# Back-End-VisionAI
VisionAI es un sistema de asistencia para personas ciegas basado en lentes inteligentes capaces de percibir el entorno mediante una cámara, procesar información mediante inteligencia artificial y comunicarse con el usuario mediante audio.
El proyecto busca evolucionar hacia un sistema de navegación indoor, permitiendo que una persona ciega pueda desplazarse dentro de un edificio que no conoce y recibir indicaciones para llegar a un destino determinado.
El primer objetivo será desarrollar el sistema para ORT, utilizando los planos disponibles del edificio y un mapa tridimensional generado previamente mediante robots cuadrúpedos equipados con sensores y cámaras.
El usuario no utilizará el robot. Este será empleado únicamente durante la etapa de relevamiento y generación del mapa.
